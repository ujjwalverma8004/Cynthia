# MY SITE - Landing Page

This is a personal landing page showcasing the profile and work of Ujjwal Verma. The site features smooth animations, interactive elements, and links to portfolio projects and social media.

## Features

- **Responsive Hero Section**: Displays animated headings with the name "UJJWAL Verma", affiliation "NIT PATNA", and status as a new web developer looking for internship.
- **Smooth Scrolling**: Implemented using the Locomotive Scroll library for a seamless scrolling experience.
- **GSAP Animations**: Page load animations for navigation bar, headings, and footer elements to create an engaging entrance effect.
- **Interactive Mouse Follower**: A small circle follows the mouse cursor, scaling dynamically based on movement.
- **Hover Effects on Portfolio Elements**: Portfolio items reveal images that move and rotate in response to mouse movement, adding interactivity.
- **Page Sections**:
  - Hero section with navigation and animated headings.
  - Portfolio links section with clickable elements linking to personal website, college, and previous work.
  - About Me section with profile image and description.
  - Subscribe section encouraging Instagram follow.
  - Footer with date/time and social media links.
- **External Links**: Links to previous work at SBPDCL, college website (NIT Patna), personal food order website, and social media profiles.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- [GSAP (GreenSock Animation Platform)](https://greensock.com/gsap/)
- [Locomotive Scroll](https://locomotivemtl.github.io/locomotive-scroll/)
- [Remixicon](https://remixicon.com/) icon library
